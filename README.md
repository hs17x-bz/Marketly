<h1>Marketly</h1>

A Full-Stack Marketplace Application

Marketly is a marketplace web application built to explore and implement the fundamentals of full-stack development, user authentication, database management, and CRUD operations.

The project allows users to create accounts, publish products, manage their own listings, browse products from other users, and purchase items.

Overview

Marketly started as a beginner project, built to understand how frontend and backend components communicate and how application data is stored and managed.

As my development skills progressed, I decided to improve the application's foundations rather than keeping its initial implementation.

One of the biggest changes was moving from local JSON files and manually assigned mock IDs to a structured MySQL database with persistent records and database-backed user authentication.

Features

- User Authentication: Account registration, login, and logout using database-stored user information.
- Product Management: Create, publish, and delete product listings.
- User Ownership: Users manage their own listings.
- Marketplace Browsing: Browse products published by other users.
- Purchasing Flow: Implemented basic marketplace purchasing functionality.
- Database Integration: Persistent data storage using MySQL.

Development Journey

1. Initial Implementation — JSON Storage

The project initially used JSON files to store application data.

At this stage, I was learning the fundamentals of backend development, including data manipulation, basic application logic, and how to connect different parts of an application.

- Data stored in JSON files.
- Manually assigned mock IDs.
- Basic user and product data management.
- Initial authentication and application logic.

2. Backend Evolution — MySQL Integration

As I gained a better understanding of databases and backend architecture, I started moving away from JSON-based storage.

I progressively upgraded the application to use MySQL for structured and persistent data management.

This transition introduced concepts such as:

- Relational database design.
- Persistent data storage.
- Database queries and data manipulation.
- Managing relationships between users and their listings.

3. Database-Backed Authentication

Another important improvement was moving towards real database-backed authentication.

Instead of relying on mock user information, the application started using registered user information stored in the database.

This helped me understand the difference between basic simulated authentication and authentication connected to persistent application data.

What I Learned

Building Markedly helped me develop a practical understanding of:

- Full-stack application development.
- PHP backend architecture and application logic.
- MySQL database integration.
- CRUD operations.
- User authentication and authorization concepts.
- Managing user-owned resources.
- The transition from temporary data storage to relational databases.
- Improving an existing application as technical knowledge grows.

Project Status

Marketly represents an ongoing learning journey in full-stack development. Its evolution reflects my progression from basic data handling to more structured backend development and database integration.
